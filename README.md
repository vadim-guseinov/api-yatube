Backend API для социальной сети Yatube, реализованный на Django REST Framework.
Проект предоставляет REST API для работы с постами, группами и комментариями. Доступ к API возможен только для аутентифицированных пользователей (аутентификация по токену). Чтение доступно всем авторизованным, создание/изменение/удаление — только автору контента.

- Python 3.10+
- Django 5.1
- Django REST Framework
- SQLite (по умолчанию)
